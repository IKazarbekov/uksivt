Работа с фигурами

Одним из способов выведения двухмерной графики это фигуры

К фигурам относсят такие элементы как Polygon многоугольник, Ellipse овал, Rectange прямоугольник, Line линия, Polyline много связанных линий.

Dispatcher object - Абстрактный класс
Dependency object - конкретный класс
Visual - Абстрактный класс
UIElement - конкретный класс
FrameworkElement - конкретный класс
Shape - Абстрактный класс

СВойства
	Fill - заполняет фон фигуры 
	Stroke - задает кисть для отображения границы
	StrokeThikness - задает толщину границы
	StrokeStartLineCap,StrokeEndLineCap - задает для незамкнутых фигур контур в начале и в конце линии соответственно
	StrokeDashArray -  задает границу фигуры в виде щьриховки создавая эффект пунктира 
	StrokeDashOffset - задает расстояние до начала штриха 
	StrokeDashCap - задает форму штрихов
	RadiusX, RadiusY - задает радиус для округления в прямоугольнике

Пример работы с Line:
	пиксели отчитываются с верхнего края и левого
	<Line X1 Y1 X2 Y2/>

Привет работы с Polygon
	<Polygon Points="50, 150, 150, 50, 259, 150"/>
