StreamReader StreanWriter

	StreamReader и StreamWriter
	Запись в файл и StreamWriter

	    Класс: StreamWriter — для записи в текстовый файл.

	    Конструкторы:

	        StreamWriter(string path) — связывает поток с файлом по пути.

	        StreamWriter(string path, bool append)— true: дозапись в конец; false: перезапись файла.

	        StreamWriter(string path, bool append, Encoding encoding) — указание кодировки. 

	Методы StreamWriter — Close

	    Close() — закрывает файл и освобождает ресурсы.

	    Для автоматического закрытия используется конструкция using () {}. 

	Методы StreamWriter — Write

	    Write(string value) — записывает данные простых типов (int, char, string и др.). Есть перегруженные версии.

	    WriteAsync()— асинхронная версия метода. 

	Методы StreamWriter — WriteLine

	    WriteLine(string value) — записывает данные и добавляет символ конца строки.

	    WriteLineAsync()— асинхронная версия. 

	Асинхронный

	    Вызываются в методе с async и оператором await.

	    Преимущества: неблокирующий UI, экономия потоков, масштабируемость. 

	Методы StreamWriter — Flush

	    Flush() — немедленно записывает буферизированные данные в файл (без закрытия потока).

	    FlushAsync()— асинхронная версия. 

	Чтение из файла

	    Класс: StreamReader — для чтения текста из файла.

	    Конструкторы:

	        StreamReader(string path) — связывает поток с файлом.

	        StreamReader(string path, Encoding encoding) — чтение с указанной кодировкой. 

	Методы StreamReader — Read

	    Read() — считывает следующий символ (в виде int). Возвращает -1 при конце файла. Есть перегрузка для чтения в массив char[].

	    ReadAsync() — асинхронная версия.

	Методы StreamReader — Peek

	    Peek() — возвращает следующий доступный символ без его считывания; при отсутствии символов возвращает -1.

	Методы StreamReader — ReadLine

	    ReadLine() — считывает одну строку.

	    ReadLineAsync() — асинхронная версия.

	Методы StreamReader — ReadToEnd

	    ReadToEnd() — считывает весь текст из файла.

	    ReadToEndAsync()— асинхронная версия. 

	Методы StreamReader — Close

	    Close() — закрывает файл и освобождает ресурсы.

	    Рекомендуется использование using для автоматического закрытия.
