1.  Теория
Какие типы данных используются в языке Python. Их отличия. Отличия изменяемых и неизменяемых типов данных.
Основные принципы объектно-ориентированного программирования.
2.  Консольное приложение
Разработать программу с использованием принципов ООП, реализующую классы:
Родительский класс: Животное (среда обитания)
Дочерние классы:
•  Лошадь (порода, имя, имя хозяина, как используется)
•  Тигр (род, сколько лет, среда обитания)
•  Змея (род, ядовитая или нет, длина)

Каждый класс обязан реализовать функцию (-> str) вывода всей информации о себе.
3.  Десктопное приложение
Используя модуль PyQt написать графический интерфейс программы и реализовать следующий функционал для разработанных дочерних классов:
-  Возможность создание экземпляров всех классов.
-  Вывод данных из JSON файла.
-  Сохранение данных в JSON файл.
