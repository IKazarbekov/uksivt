Билет 1
    1. ОС – комплекс программ, управляющий ресурсами ПК и обеспечивающий взаимодействие пользователя с аппаратурой. Назначение: управление ресурсами, интерфейс, выполнение программ. Виды: Windows, Linux, macOS, мобильные, реального времени.
    2. API (Application Programming Interface) – интерфейс программирования приложений, набор готовых функций. В ОС API – это системные вызовы (syscalls) и библиотеки для взаимодействия программ с ядром.
Билет 2
    1. ФС – часть ОС для организации хранения, именования и доступа к данным на носителе. Назначение: управление файлами и каталогами. Виды: FAT32, NTFS, ext4, APFS.
    2. Быстрое: очищает оглавление диска (таблицу файлов), данные остаются, восстановить легко. Полное: стирает данные (записывает нули), проверяет сектора, долго.
Билет 3
    1. Через команду move в cmd. Пример: move C:\source\file.txt D:\destination\.
    2. Теневая копия (Volume Shadow Copy) – моментальный снимок файла/тома для резервного копирования без остановки работы. Присутствует в NTFS.
Билет 4
    1. Централизованные ОС работают на одном компьютере. Распределённые – на нескольких машинах в сети, представляя их как единую систему.
    2. В Rufus: выбрать флешку, указать ISO-образ, схему раздела (GPT/MBR), начать запись. Для создания ISO: в меню выбрать "Создать загрузочный диск" -> "ISO-образ".
Билет 5
    1. Классификация: дисковые (FAT, NTFS), сетевые (NFS), виртуальные (procfs), специализированные (для флеш-памяти). Специфика: структура, ограничения, надёжность, назначение.
    2. Файловый менеджер – программа для управления файлами и каталогами (проводник, Total Commander).
Билет 6
    1. Одноуровневые ФС (ранние ОС, DOS): все файлы в одном каталоге. Иерархические (современные ОС): древовидная структура с папками и подпапками.
    2. Файл подкачки (pagefile.sys) – область на диске для расширения виртуальной памяти. Находится на системном разделе.
Билет 7
    1. Функции ФС: именование, организация хранения, доступ, защита, совместное использование, обеспечение целостности.
    2. touch newfile.txt или > newfile.txt (создать пустой). nano newfile.txt (создать и открыть в редакторе).
Билет 8
    1. Кластер – минимальная единица хранения данных на диске. Свойства: размер кратен сектору, файл занимает целое число кластеров.
    2. echo.> newfile.txt или type nul > newfile.txt (пустой). copy con newfile.txt (создать с вводом текста, Ctrl+Z для сохранения).
Билет 9
    1. BIOS – базовая система ввода-вывода, прошивка для инициализации аппаратуры и загрузки ОС. Черты: работает в 16-битном режиме, интерфейс текстовый. Предназначение: POST, загрузчик, настройка оборудования.
    2. Ввести имя исполняемого файла с расширением .exe или .com и нажать Enter. Пример: program.exe.
Билет 10
    1. Способы: извлечь батарейку CMOS на материнской плате, перемычка Clear CMOS, ввод инженерного пароля, сброс через ПО.
    2. Команда mklink. Пример ярлыка (символической ссылки): mklink C:\link.lnk "C:\target.exe".
Билет 11
    1. Windows (семейство Windows NT), Linux (семейство Unix-подобных, ядро Linux), macOS (семейство Unix, BSD-основа). Вклад: унификация, доступность, развитие сетей, открытость.
    2. Защита: разграничение прав доступа (пользователи, ACL), шифрование, брандмауэр, антивирус. Угрозы: вирусы, черви, трояны, шпионское ПО, фишинг.
Билет 12
    1. Конфигурация устройств (devmgmt.msc) – управление драйверами. Управление дисками (diskmgmt.msc) – работа с разделами. Редактор реестра (regedit) – база данных настроек Windows.
    2. Основные функции ОС: управление процессами, памятью, устройствами ввода-вывода, файлами. Дополнительные: сетевые службы, интерфейс пользователя, мультимедиа.
Билет 13
    1. Диспетчер задач (Ctrl+Shift+Esc) – мониторинг процессов и ресурсов. Диспетчер устройств (см. выше). Командная строка (cmd) – интерфейс для ввода команд.
    2. Состав: ядро, драйверы, системные библиотеки, оболочка (shell), утилиты.
Билет 14
    1. В VirtualBox: создать новую виртуальную машину, выделить ресурсы, выбрать ISO-образ Windows, запустить и следовать шагам установщика.
    2. Ядро – центральная часть ОС, управляющая аппаратными ресурсами. В монолитной – все компоненты в одном адресном пространстве. В микроядерной – минимальное ядро, остальные службы в пользовательском режиме.
Билет 15
    1. Дефрагментация – процесс упорядочивания фрагментированных файлов на диске для ускорения доступа. Выполняется утилитами (defrag). Фрагментация – разбиение файла на разрозненные фрагменты. Причина: многократная запись/удаление файлов.
    2. Восстановление: из корзины, предыдущих версий (теневые копии), ПО для восстановления данных (Recuva), резервных копий.
Билет 16
    1. Характерность Linux: открытое ПО (ядро GNU/Linux), многопользовательский, многозадачный, безопасность, множество дистрибутивов.
    2. Создать загрузочную флешку, в BIOS/UEFI выбрать загрузку с USB, следовать шагам установщика Windows.
Билет 17
    1. CD/DVD-привод нужен для чтения и записи оптических дисков (установка ОС, программы, мультимедиа).
    2. Через Сведения о системе (msinfo32), Диспетчер устройств, командную строку (wmic csproduct get name), либо посмотреть на корпусе/в BIOS.
Билет 18
    1. Компьютерная сеть – система связи между компьютерами. Виды: LAN (локальная), WAN (глобальная). Типы: по топологии (шина, звезда), по архитектуре (клиент-сервер, одноранговая).
    2. Облачная ОС – ОС, работающая в браузере или на удалённом сервере (Chrome OS). Специфика: данные и приложения в облаке, минимальные требования к клиенту.
Билет 19
    1. Мейнфрейм – высокопроизводительный компьютер для обработки больших объёмов данных и критических задач. Особенности: отказоустойчивость, высокая надёжность, масштабируемость.
    2. Черты iOS: закрытая система, экосистема Apple, безопасность, оптимизация под железо, App Store.
Билет 20
    1. Черты Android: открытая платформа (на базе Linux), для смартфонов/планшетов, магазин приложений Google Play, кастомизация.
    2. Страничное распределение памяти – разделение памяти на фиксированные страницы для виртуальной памяти. Особенности: уменьшение внешней фрагментации, использование таблицы страниц.
Билет 21
    1. Сетевая ОС: 1) ОС, предоставляющая сетевые службы (файловый, печати). 2) ОС для управления сетевыми ресурсами (серверные ОС).
    2. Микроядерная архитектура – ядро минимально, основные службы (драйверы, файловая система) работают в пользовательском режиме. Особенности: высокая стабильность, модульность, безопасность.
Билет 22
    1. Привилегированный режим (режим ядра) позволяет выполнять любые машинные инструкции и доступ ко всей памяти. Ядро работает в нём для управления аппаратурой.
    2. MS-DOS – дисковая ОС от Microsoft для IBM PC. Черты: однозадачная, командная строка, 16-битная, FAT.
Билет 23
    1. UEFI – современный интерфейс замены BIOS. Особенности: графический интерфейс, безопасная загрузка (Secure Boot), поддержка дисков >2 ТБ, сетевая загрузка.
    2. Популярные дистрибутивы Linux: Ubuntu (удобство), Debian (стабильность), Arch (минимализм, кастомизация), Fedora (новые технологии), Mint (удобство для новичков).
Билет 24
    1. Серверные ОС предназначены для управления сетевыми ресурсами и службами. Функции: централизованное управление, безопасность, отказоустойчивость, поддержка серверного ПО.
    2. Виды угроз: Вирусы (внедряются в файлы), черви (распространяются по сети), трояны (маскируются), шпионское ПО (сбор данных), ransomware (шифрование). Методы: уязвимости ПО, социальная инженерия.

Билет 30
    1. Брандмауэр Windows – встроенный сетевой экран для фильтрации входящего/исходящего трафика по правилам.
    2. Антивирус – программа для обнаружения, блокировки и удаления вредоносного ПО. Функции: сканирование, мониторинг, эвристический анализ, карантин.
